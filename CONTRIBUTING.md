# Feedback and contributions

Mongrel Dictionary is source-available under PolyForm Perimeter 1.0.1. Read [LICENSE](LICENSE), [NOTICE.md](NOTICE.md), and [the design philosophy](PHILOSOPHY.md) before proposing a change. Public access is not an open-source license.

Small, reproducible reports are useful: include the app build, macOS version, Mac model, lookup mode, and the behavior you expected. Review any attachment for private information. The [feedback form](https://github.com/fwalterj/mongrel-dictionary-app/issues/new?template=feedback.yml) includes accessibility and interaction problems.

For code changes, explain the observation, the decision, its boundaries, and how the intersections with existing behavior were verified. Start from the existing implementation. Preserve offline operation, source attribution, user data, keyboard access, and Black/White Contrast. Run the source verification described in [DEVELOPMENT.md](DEVELOPMENT.md); corpus-dependent changes need additional evidence with suitable data.

Contribute only work you have the right to offer under the repository's applicable terms. Identify third-party material and its license rather than relabeling it as Mongrel code. Copyright remains with the relevant author; submitting a pull request does not transfer ownership. Discuss contributions that need different terms before submitting them.

Do not upload research corpora, reference-book excerpts, private dictionaries, user data, credentials, app installers, or generated build directories. A dataset being downloadable is not evidence that its contents can be redistributed here.
